Biomass can make coal and other fossil fuels feuls longer.

One reason why biomass should be used as equally as coal is because it would make coal last longer. If people spend billions of dollars on “cleaner” renewable energy, like wind and solar, there may be some times when there is too little energy, since these turning these sources of energy effectively are still a work in progress.

Biomass, on the other hand, would not require too much technology to use because there is simply one way to make energy out of the material, the same way or ancestors did: burning it. Many third-world countries are already using biomass, but using this more will allow more time to find a more reliable source of energy. Biomass is a renewable energy source because it grows faster than it burns. If biomass is burned as equally as coal, it would potentially increase the amount of time before it runs out.
